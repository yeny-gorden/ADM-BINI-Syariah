# BINI-Syariah
Bini Syariah adalah aplikasi perbankan mini/koperasi berbasis web &amp; APK (Android) dengan arsitektur terpisah antara Admin (admin.html) dan Nasabah (nasabah.html). Menggunakan backend Google Sheets &amp; Apps Script real-time, lengkap dengan fitur QR scanner kamera asli, mutasi kas, transfer, dan cetak PDF struk otomatis.
